My first week was mainly about getting oriented with the FCAJ program and preparing the AWS account I would use throughout the internship. On the technical side, I secured the root account, created a separate administrator identity, and configured cost alerts.

### Notes from the work

I stopped using the root identity for routine work after creating the administrator user. I then signed in with the new identity and checked that its permissions worked as expected. The AWS Budgets exercise was useful because the four budget types initially looked similar; creating each one made the difference between cost and usage tracking much clearer.

### End-of-week result

The AWS environment was ready for the following labs. More importantly, I had a basic routine in place: check account access and cost controls before creating new resources.
