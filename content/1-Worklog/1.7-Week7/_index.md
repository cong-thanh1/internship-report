### Focus for the week

I started the SmartStudy AI project in Week 7. The initial idea was a study application built around a student's own material: upload a document, ask questions about it, generate a practice quiz, and review the result.

### Decisions and adjustments

The first architecture draft considered Amazon Bedrock and vector storage for the AI/RAG layer. At this point, these were design options rather than deployed components. I kept the scope to the smallest set of features needed for a complete user flow and left classroom-management features out until the core workflow had been validated.

### End-of-week result

SmartStudy AI had a defined scope, an initial architecture diagram, and a module-based task list. These became the starting point for the interface, API, and document-processing work in Week 8.
